🔁 自动故障切换

某个后端超时、宕机、限流时，自动切到下一个可用后端，调用方无需关心哪些服务可用 —— 这就是 Unstop 的意义。

🧩 多模型多后端

每个 API Key 下可创建多个逻辑模型；每个模型可按协议（OpenAI 兼容 / Anthropic 兼容等）配置多组真实服务。
